Déployer

Qu'est-ce qui empêche l'agent de passer à côté ?

Chaque déploiement répond à trois questions : où tourne l'agent, où tourne le modèle, et ce qui l'empêche de contourner le superviseur. Plus la réponse à la troisième est solide, plus le niveau d'assurance est élevé.

Niveaux d'assurance

De la coopération au confinement.

Niveau 1

Coopératif

Le hook de Claude Code soumet chaque action. Un script lancé par l'agent peut sortir sans être vu.

Niveau 2

Sur le chemin

Le proxy LLM et la passerelle MCP voient ce que demande le modèle : raisonnement, secrets, contrôle croisé.

Niveau 3

Confiné

L'agent tourne dans un conteneur sans route vers l'extérieur. Ses seules sorties sont les passerelles.

Démarrer

Un premier projet supervisé en 15 minutes.

Niveau 1 d'abord. Le confinement se met en place ensuite, quand le hook marche. Il faut macOS ou Linux, Rust 1.80 ou plus et Claude Code.

  1. Construire 
    git clone https://github.com/bdudout/aplomb.git
cd aplomb
cargo build --release
cargo install --path crates/aplomb
    Pour tout vérifier sans rien toucher du réel : scripts/banc.sh monte une instance jetable et doit finir par 104 vérifications réussies.
  2. Créer son instance 
    mkdir -p ~/aplomb-instance/mandats && cd ~/aplomb-instance
cp -R <clone>/profils .
cp <clone>/exemples/mandat.yaml mandats/mon-projet.yaml
    Puis adapter le mandat : racine du dépôt, domaines autorisés, intention.
  3. Initialiser la gouvernance 
    aplomb init --membre alice --membre bob
    Une phrase de passe, deux comptes, un seuil de deux signatures, mandats cosignés.
  4. Lancer le superviseur 
    aplomb serve --mandat mandats/mon-projet.yaml
    Il vérifie les signatures et crée cles/reponses.pub, la clé qui signe ses réponses.
  5. Brancher Claude Code Déclarer aplomb hook --cle-serveur …/cles/reponses.pub en PreToolUse et PostToolUse dans .claude/settings.json du dépôt.
  6. Vérifier Demander à Claude Code de lancer les tests (autorisé), puis curl https://example.com (refusé). Ouvrir Aplomb Watch avec aplomb admin --compte alice connexion, puis aplomb verify --journal journal.

Pas à pas complet, confinement, modèle local, serveurs MCP et juge : installation dans le README.
